🎵 Mes concerts

Les concerts de vos artistes préférés, sur votre téléphone

Télécharger l'application

Installer, pas à pas

  1. Touchez le bouton violet ci-dessus. Si Chrome prévient que le fichier « peut être dangereux », touchez Télécharger quand même.
  2. Quand le téléchargement est fini, touchez Ouvrir (ou ouvrez l'appli Fichiers, puis Téléchargements, puis mes-concerts.apk).
  3. Le téléphone demande l'autorisation d'installer des applis venant de Chrome : touchez Paramètres, activez Autoriser depuis cette source, puis revenez en arrière.
  4. Touchez Installer. Si Google Play Protect affiche « Application inconnue » ou « Appli non vérifiée », touchez Plus de détails puis Installer quand même. S'il propose d'envoyer l'appli pour analyse, vous pouvez accepter ou refuser, cela ne change rien.
  5. Ouvrez Mes concerts. Touchez Autoriser les notifications, puis Autoriser sur le bandeau « arrière-plan » : c'est ce qui permet à l'appli de vous prévenir chaque jour.

Mise à jour : même bouton, même manipulation. La nouvelle version s'installe par-dessus l'ancienne et garde vos artistes.

Application privée, faite par Mathéo. Elle ne collecte rien : tout reste sur votre téléphone.
